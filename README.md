# URL to PDF Converter

A Python tool for turning cluttered web tutorials into clean, offline PDFs — because some websites just love their ads a little too much.

Ever followed a programming tutorial where every section is a separate webpage, surrounded by cookie banners, pop-ups, and weird sidebar junk? Yeah, me too.

This script lets you batch-convert a list of URLs into clean PDF files — perfect for building your own offline, distraction-free programming book.

No frills. No ads. Just content.

# Why I Built This

Simple. I got tired of clicking "next page" and dodging ads while trying to learn.

This project was part of my programming studies, and like most of my tools, I built it to solve a personal annoyance. Bonus: it gave me an excuse to mess around with GUI design and basic automation.
